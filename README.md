# Ecommerce Frontend Design

## Frontend

```bash
npm install
npm run dev
```

Runs at:
http://localhost:5173

## Backend

```bash
cd backend
npm install
npm run dev
```

Runs at:
http://localhost:5000

## API Endpoints

GET /api/products

GET /api/products/:id

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB Atlas
- Axios

## Environment Variables

Create a `.env` file inside the backend folder:

```
MONGO_URI=your_mongodb_connection_string
PORT=5000
```
